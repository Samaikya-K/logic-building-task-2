# Logic Building Task-2 – Python Practice Problems

## Overview

This repository contains solutions to 10 Python logic building problems.
The objective of this task is to strengthen programming fundamentals and problem-solving skills using basic Python concepts.

The programs cover:

* Lists
* Dictionaries
* Sets
* Tuples
* Loops and Conditions
* Basic calculations

All programs are written in Python and executed inside a Jupyter Notebook with outputs included.

---

## Problems Covered

1. Unique Words in a Sentence
2. Highest Salary from Employee Data
3. Find Maximum and Minimum Values
4. Count Products Above a Price Threshold
5. Calculate Attendance Percentage
6. Remove Duplicate Phone Numbers
7. Count Character Frequency
8. Convert List to Tuple
9. Check if a Key Exists in a Dictionary
10. Calculate Average Marks

---

## How to Run

1. Open the `.ipynb` notebook file using Jupyter Notebook or Google Colab
2. Run all cells (Run → Run All)
3. Outputs will be displayed below each program

## Technologies Used

* Python 3
* Jupyter Notebook
